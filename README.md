# Grade9_POS_Ordering_System
A simple console-based Point-of-Sale ordering system built with Python.

Description
This program displays a product menu, allows customers to select items and quantities, calculates subtotals, and generates a final receipt with the total amount to pay. Built as a collaborative pair project using Git, GitHub, and VS Code.

 Developers
- Developer 1: Sheehan Grace Maduro
- Developer 2: Lady Zyrich Fesalbon

 Features
- Display product menu with prices
- Multiple item ordering
- Automatic subtotal and total calculation
- Clean formatted receipt output

How to Run
1. Open the file in Python 3.x
2. Run the program
3. Follow the on-screen prompts to place your order
4. Enter 'n' when finished to view your receipt
